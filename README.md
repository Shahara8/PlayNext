# PlayNext

Find where to watch a movie or show across streaming services (Netflix, YES, etc.), sort/filter/search the catalog, track favorites/watchlist/ratings, and get basic recommendations.

See [`docs/MVP.md`](docs/MVP.md) for product scope, architecture, and the implementation plan, and [`docs/INGESTION.md`](docs/INGESTION.md) for the catalog ingestion pipeline design.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
